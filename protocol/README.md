# protocol/

Machine-readable test vectors for the kitedrop wire protocol. The specification is
[docs/protocol.md](../docs/protocol.md).

- `vectors/*.json` — generated by `cargo run -p kitedrop-core --example gen_vectors`. Deterministic: all keys
  and randomness derive from fixed labels, so regenerating produces identical files. `cargo test` fails when
  the files are stale.
- `vectors/rfc9180-subset.json` — copied from the official RFC 9180 vectors (source URL inside); not generated.

Byte strings in vectors are lowercase hex; binary fields inside wire-format JSON objects are base64url without
padding, exactly as on the wire.
